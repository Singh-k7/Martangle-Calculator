# Martangle Calculator

Martangle Calculator ek halka-phulka, user-friendly web calculator project hai jo JavaScript, HTML, aur CSS se bana hua hai. Is README ka maksad hai project ko aasaan aur insani zubaan mein samjhana — taaki koi bhi developer ya user jaldi se samajh sake ki yeh kya karta hai aur kaise use kiya ja sakta hai.

## Kya hai yeh project?
Martangle Calculator ek simple aur responsive calculator web app hai jo aam zarooriyat ke liye basic arithmetic operations support karta hai. Yeh chhota, saaf, aur mobile-friendly UI ke saath bana hai taki aap turant use kar saken.

## Bunyadi features
- Basic arithmetic: +, -, ×, ÷
- Clear aur delete functions
- Responsive layout — mobile aur desktop dono par ache se dikhai deta hai
- Clean aur minimal UI (HTML/CSS)

## Technology stack
- JavaScript (logic)
- HTML (structure)
- CSS (styling)

## Kaise chalayein (Local)
1. Repository clone karein:

   git clone https://github.com/Singh-k7/Martangle-Calculator.git

2. Project folder mein jaayein:

   cd Martangle-Calculator

3. Simple way: index.html ko apne browser mein open karein (double-click ya right-click -> Open with browser).

4. Developer-friendly way: agar aapne VS Code use kiya hai toh "Live Server" extension se bhi chalaa sakte hain:
   - VS Code mein folder kholo
   - Right-click on index.html -> Open with Live Server

## Project structure (short)
- index.html — app ka entry point
- styles.css — styling (agar alag file hai)
- script.js — main JavaScript logic
- assets/ — (agar images ya icons ho)

> Note: Agar actual filenames aapke repo mein thode alag hain, toh upar wale paths ko match kar lijiye.
