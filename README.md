# MartaCalc

MartaCalc is a lightweight, responsive web calculator built with HTML, CSS, and JavaScript. It’s designed to be simple, fast, and easy to use on both mobile and desktop.

## What is MartaCalc?
A small calculator web app for everyday arithmetic — add, subtract, multiply, and divide. It has a clean, minimal interface and works well across screen sizes.

## Features
- Basic arithmetic: +, −, ×, ÷
- Clear (AC) and backspace/delete
- Responsive layout for mobile and desktop
- Minimal, easy-to-read UI

## Tech stack
- JavaScript — logic
- HTML — structure
- CSS — styling
